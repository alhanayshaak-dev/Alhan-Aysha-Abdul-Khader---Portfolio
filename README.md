# Alhan Aysha Abdul Khader – Achievement Portfolio

A single-page portfolio. Every piece of evidence is built into the page as a dossier card, with its certificate image stored in the `ev` folder.

## Publish on GitHub Pages

1. Sign in at github.com and create a new public repository named `alhan-portfolio`.
2. Unzip this package. On the empty repository page choose "uploading an existing file", drag in the `ev` folder and commit. Then choose Add file → Upload files and drag in everything else (the `studio` folder, `index.html`, `style.css`, `app.js`, `data.js`, `portrait.webp`, `README.md`, `.nojekyll`, `manifest.webmanifest`, `icon.svg`, `sw.js`) and commit.
3. Open Settings, then Pages. Under "Build and deployment" choose "Deploy from a branch", select `main` and `/ (root)`, and save.
4. After a minute or two the site is live at `https://<your-username>.github.io/alhan-portfolio/`.

## Privacy

Report cards, assessment reports, mark sheets, emails and peer notes are not included. Cards for those show a short summary instead.

## Install as an app

On a phone, open the site and choose Add to Home Screen. On a computer in Chrome or Edge, use the install icon in the address bar.
